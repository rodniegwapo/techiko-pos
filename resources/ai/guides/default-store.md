title: Make a store the default
page: inventory.locations.index
requires: inventory.locations.set-default
keywords: default store, main store, set as default
---
1. In the sidebar, open **Inventory → Locations**.
2. Open the store's actions and choose **Set as default**.
3. Staff without an assigned store now work in this store. The current default shows a **Default** tag.
