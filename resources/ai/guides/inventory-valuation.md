1. In the sidebar, open **Inventory → Valuation Report**.
2. The top shows **Total Inventory Value** (at cost), **Retail Value (at sale price)** and **Potential Profit**.
3. The list shows each product's quantity, **Avg cost**, **Sale price** and **Retail value**.
4. Use the filters to narrow it down, then **Export** or **Print**.
